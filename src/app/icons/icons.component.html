Guide d'utilisation de la plateforme

Consultez les instructions ci-dessous pour bien utiliser les fonctionnalités proposées.

  • 🔐 Connexion : Connectez-vous avec vos identifiants pour accéder à votre espace.
  • 📤 Soumission : Allez dans "Bulletins de soin" et cliquez sur "Nouveau" pour soumettre un bulletin.
  • 🧾 Fichier : Téléversez un fichier PDF clair, lisible et correctement rempli.
  • 📊 Suivi : Consultez le tableau de bord pour voir le statut de vos demandes.
  • ✉️ Réclamation : En cas de refus injustifié, accédez à "Réclamations" pour contester une décision.
  • 📬 Notifications : Vérifiez vos emails ou les alertes dans l'interface pour les mises à jour.
  • 📁 Historique : Vous pouvez consulter toutes vos actions dans la section "Historique".
Le guide est visible en version bureau. Utilisez un ordinateur pour plus de détails.
